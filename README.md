# Jayam Srivastava — Portfolio

A responsive, buildless portfolio with a scroll-responsive folding hero and original CSS project artwork.

## Run
Serve `dist/` with any static HTTP server. No dependencies or build step required.

## Edit
- `dist/index.html`: biography, projects, links and metadata
- `dist/style.css`: visual design, responsive layouts and CSS animation
- `dist/app.js`: scroll transforms, reveal behavior, motion controls, time and clipboard interaction

Content was sourced from the authenticated GitHub profile hrx01-dev and its public profile README on 2 November 2026. Artwork is conceptual, not screenshots of the projects.

## Credits
The `.skiper-link` CSS interaction adapts Skiper UI's free Skiper40 Link000 underline animation from https://skiper-ui.com/registry/skiper40.json. Author: @gurvinder-singh02 / https://gxuri.me. Skiper credits Cursor as its inspiration. Attribution is included in the site footer. The rest of the artwork and implementation is original; the Fold Line template was used as a conceptual reference, not copied.

Motion respects the operating-system reduced-motion preference and can also be paused using the hero control. The site has no analytics, form backend or tracking.
